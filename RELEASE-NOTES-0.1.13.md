# Altbase Wallet 0.1.13 integration

Repository: `AltbaseWallet/module-arbitrum`.

Installable PublicNode account module metadata and binary bootstrap. Build the platform library using the main wallet account-module builder and shared account-common/adapter repositories. Native/token MAX, manual token import, on-demand icons, hidden spam controls and unavailable-read preservation are verified with offline fixtures.

See the main wallet changelog for the complete release notes. Compilation and signing verification use isolated/public fixtures; release QA does not submit user transfers. Generated platform libraries and private wallet implementation files are excluded from new source uploads.
